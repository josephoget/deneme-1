# Piyasa Masası

GitHub Pages giriş dosyası depo kökündeki `index.html` dosyasıdır. `market.css`, `market.js` ve `market-data.js` aynı dizinde kalmalıdır. Eski `aselsan-teknik-analiz.html` adresi ana sayfaya yönlenir.

## GitHub Pages yayını

1. Bu dosyaları GitHub deponuzun varsayılan dalına yükleyin.
2. Depoda **Settings → Pages → Build and deployment** bölümünü açın.
3. **Source: Deploy from a branch**, dal olarak varsayılan dalı ve klasör olarak **/(root)** seçip kaydedin.
4. Yayın adresi `https://KULLANICI.github.io/DEPO/` olur. Depo adı `KULLANICI.github.io` ise adres `https://KULLANICI.github.io/` olur.

Fiyat verileri sayfaya gömülü tarihsel kesittir; yayınlandıktan sonra otomatik güncellenmez. Güncel analiz için `market-data.js` içindeki verilerin yenilenmesi gerekir.
